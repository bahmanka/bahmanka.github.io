# B. K. A. — Personal Portfolio

A bilingual, responsive one-page portfolio for Bahman Kiani Azad. Built with plain HTML, CSS and JavaScript for GitHub Pages.

## Files
- `index.html` — page structure and content
- `styles.css` — visual system and responsive layout
- `script.js` — language switcher and exhibition detail modal

## Before launch
1. Set this repository to **Public** if using GitHub Free for GitHub Pages.
2. In **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/(root)`.
3. Review exhibition names, galleries and dates for accuracy.
4. Add the final English CV PDF and connect the Download CV control.
5. Replace or expand the placeholder project information when details are ready.

The art portfolio remains separate at https://bahmanka.github.io/artwork/biography.html.
